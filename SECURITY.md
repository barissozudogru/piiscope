# Security Policy

## Supported Versions

| Version | Supported |
| ------- | --------- |
| 1.x     | Yes       |
| < 1.0   | No        |

## Reporting a Vulnerability

Please report security vulnerabilities using [GitHub private vulnerability reporting](https://github.com/barissozudogru/piiscope/security/advisories/new) on the repository. The maintainer will respond within 7 days.

## Scope

**In Scope:**
- The piiscope CLI and library.
- The reference server (FastAPI, Celery) and UI provided in this repository.

**Out of Scope:**
- Vulnerabilities in third-party dependencies (unless they require a version bump in piiscope).
- Issues related to how you deploy or expose the reference server in production environments.

## Data Handling

The piiscope CLI processes files locally on your machine. It never sends your data or files to any external server or API. Reports generated by piiscope redact sample values to prevent unintentional leakage of personal data.

## Disclosure Policy

When a vulnerability is reported, the maintainer will work with you to understand the issue and develop a fix. Once the fix is ready, a security advisory will be published along with a patched release.
